# Data Warehouse and Analytics Project
Welcome to the **Data Warehouse and Analytics Project** repository.

This project showcases a comprehensive data warehousing and analytics solution, covering the entire process from building a data warehouse to generating actionable business insights. It is designed as a portfolio project to demonstrate practical data engineering and analytical skills.


Building a modern data warehouse with SQL Server, including ETL processes, data modeling, and analytics

## Project Requirements

The project will implement an end-to-end data warehousing and analytics solution with the following requirements:

### 1. Data Sources

* CSV files
* ERP data

### 2. Bronze Layer

* Store raw source data in tables.
* Support batch and full-load processing.
* Use truncate-and-insert loading.
* No transformations will be applied.
* Preserve source data as closely as possible.

### 3. Silver Layer

* Store cleaned and processed data in tables.
* Support batch and full-load processing.
* Apply data cleaning and standardization.
* Perform data normalization and enrichment.
* Create derived/calculated columns.
* Ensure data is consistent and suitable for analytics.

### 4. Gold Layer

* Provide business-ready data through views.
* No direct data loads.
* Apply business logic, data integration, and aggregations.
* Implement analytical models such as:

  * Star Schema
  * Fact Tables
  * Flat Tables
  * Aggregated Tables

### 5. Data Consumption

The final data should support:

* Reporting and Business Intelligence
* SQL-based analytical queries
* Machine Learning use cases

### 6. Overall Objective

Build a reliable and maintainable data pipeline that transforms raw data into clean, integrated, and business-ready information for analytics and decision-making.
